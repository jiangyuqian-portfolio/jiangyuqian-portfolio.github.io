# 姜玉倩 · 数据分析作品集

两个数据分析案例的展示网站：

- **案例 01 · Olist 电商用户分析**（`olist.html`）：用 SQL 拆解巴西电商近 10 万笔订单，分析增长来源、复购和差评成因，给出物流优先的改进建议。
- **案例 02 · 落地页 A/B 测试**（`ab.html`）：约 29 万用户的实验分析，包括分流问题排查、SRM 检验、z 检验、置信区间与功效分析，给出不上线的决策建议。

纯静态页面（HTML + CSS + 原生 JavaScript），不依赖任何外部资源，可直接部署到 GitHub Pages。

数据来源：Olist Brazilian E-Commerce Public Dataset、Kaggle E-commerce A/B Testing（ab_data.csv），均为公开数据集，原始数据未包含在本仓库中。
