案例 02 · 实验分析

实验结果不显著时，新落地页是否上线

某电商网站以约 29 万用户、为期 22 天测试新版落地页，结果不显著。本案例先验证实验的有效性，再结合置信区间与功效分析，将“不显著”转化为明确的上线决策。

新页面相对提升的上限仅为 0.8%，低于 2% 的上线门槛；若要检测 1% 的提升，还需近半年，继续测试成本过高。

实验本身可信两组各占 50.0%，SRM 检验 p = 0.84。3,893 名用户同时接触了新旧页面，已整组剔除。
新页面无显著提升，且可排除达到上线标准的提升差异 −0.14 个百分点，95% 置信区间 [−0.38, +0.09]。当前样本量可在 80% 功效下检测 2.8% 以上的提升，本次未检测到。
结论通过多项稳健性检验未发现新奇效应；按工作日 / 周末及访问时段分群均不显著；更换数据清洗方式后结论不变。

1 · 先检查实验本身

数据是否可信？分组是否存在问题？

实验设计为：对照组访问旧页面，实验组访问新页面，每位用户仅分组一次。原始数据共 294,478 行，检查中发现两个问题，二者实为同一原因：

发现数量说明
分组和页面对不上3,893 行例如对照组用户看到了新页面
用户重复出现3,894 人每人出现 2 次
两者的关系100%不一致记录全部来自重复用户，这些用户同时接触了新旧页面

这些用户受两个页面共同影响，无法归入任何一组，因此将 3,893 人整组剔除（占 1.3%）。剔除前检验了偏差风险：其记录在“对照组 / 实验组 × 旧页面 / 新页面”四种组合中各有 1,900–2,000 条，分布均衡，判断为对两组影响相同的分流 bug，剔除不会造成偏向。另有 1 名重复用户的两条记录分组均正确，保留其最早一条。

常见做法是仅删除不一致的记录，但这会保留同时接触两个页面的用户。稳健性检验中对两种做法分别计算，结论一致。

清洗后，对照组 143,293 人，实验组 143,398 人。用卡方检验对比 50/50 的设计比例，p = 0.84，不存在样本比例失衡（SRM）。该检验是后续分析成立的前提。

SQL 要点：识别污染用户并整组剔除
DROP TABLE IF EXISTS ab_clean;
CREATE TABLE ab_clean AS
WITH bad AS (   -- 任何一条记录分组与页面不一致的用户
  SELECT DISTINCT user_id FROM ab_raw
  WHERE ("group" = 'control') != (landing_page = 'old_page')),
r AS (
  SELECT a.*, ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY timestamp) AS rn
  FROM ab_raw a
  WHERE user_id NOT IN (SELECT user_id FROM bad))
SELECT user_id, timestamp, date(timestamp) AS day, "group", landing_page, converted
FROM r WHERE rn = 1;

2 · 新页面有没有效果

新页面的转化率比旧页面高吗？

旧页面转化率 12.02%（17,220 / 143,293），新页面 11.87%（17,025 / 143,398）。双样本比例 z 检验 p = 0.23；如果只检验“新页面更好”这一个方向，p = 0.88。

不显著不等于没有结论

仅报告“p > 0.05，不显著”并不充分。不显著可能源于新页面确实无效，也可能源于样本量不足。区分二者需要考察两项指标：

  • 置信区间：相对提升的 95% 置信区间是 [−3.2%, +0.8%]，即新页面最乐观的情况下仅比旧页面高 0.8%。
  • 最小可检测效应（MDE）：在 5% 显著性和 80% 功效下，这个样本量能可靠检测出 0.34 个百分点（相对 2.8%）以上的提升。
假设相对提升达到 2% 才能覆盖新页面的开发与维护成本。置信区间上限 0.8% 明显低于该门槛，因此可以较有把握地判断：新页面未达到上线标准。
Python 要点：z 检验、置信区间与 MDE
from scipy import stats
import numpy as np

pc, pt = xc / nc, xt / nt                       # 两组转化率
p_pool = (xc + xt) / (nc + nt)
z = (pt - pc) / np.sqrt(p_pool * (1 - p_pool) * (1/nc + 1/nt))
p_two_sided = 2 * (1 - stats.norm.cdf(abs(z)))

se = np.sqrt(pc*(1-pc)/nc + pt*(1-pt)/nt)       # 置信区间用非合并标准误
ci = (pt - pc - 1.96*se, pt - pc + 1.96*se)

# 最小可检测效应：alpha = 0.05（双侧），power = 0.8
z_a, z_b = stats.norm.ppf(0.975), stats.norm.ppf(0.80)
mde = (z_a + z_b) * np.sqrt(pc*(1-pc) * (1/nc + 1/nt))

3 · 结论是否稳健

结果是否受时间、人群或数据处理方式影响？

效果随时间稳定，没有新奇效应

新奇效应指用户因新鲜感在短期内表现更积极，随后效果减弱。将实验分为前后两半：前半段差异 +0.02 个百分点，后半段 −0.29 个百分点，两者差异不显著（p = 0.20）。逐日累计效果显示，置信区间随样本增加逐渐收窄，但始终包含 0。

该图同时体现了“中途偷看”的风险：单日差异在 −0.94 至 +1.36 个百分点之间波动，若依据某日结果提前结束实验，容易误判。本次 22 天中，累计 p 值最低为 0.13。逐日 p 值仅用于描述过程，未用于决定停止时间；如需持续监测，应事先采用序贯检验。

分群：未发现对新页面反应更积极的用户群

按工作日 / 周末及访问时段划分的 6 个分群均不显著。周末和凌晨时段新页面略差（p = 0.06 和 0.09），但多重比较下出现接近显著结果的概率较高，经 Bonferroni 校正后分别为 0.38 和 0.53。上述结果可作为下一轮实验的线索，不构成结论。

换一种清洗方式，结论不变

若仅删除不一致记录并按用户去重（常见但不够严谨的做法），差异为 −0.16 个百分点，p = 0.19；不做清洗时，差异为 −0.15 个百分点。三种处理方式结论一致。

4 · 是否继续测试

延长测试时间能否检测到效果？

实验每日新增用户约 13,000 名。以 12% 的基线转化率计算，检测不同幅度提升所需的天数如下：

本次 22 天可检测约 3% 的提升；检测 2% 需 45 天，检测 1% 需 178 天。鉴于置信区间显示真实提升至多 0.8%，即使延长半年，最理想的结果也只是确认一个未达上线标准的小幅提升。因此建议停止测试，将流量用于下一版方案。

5 · 业务落地

决定不上线后，团队的下一步行动是什么？下一轮实验如何改进？

实验前应明确的规则

评估指标与上线条件应在实验开始前确定，避免结果出来后事后归因。结合本次实验，规则如下：

类型指标作用
主指标转化率决定上不上线
护栏指标客单价、跳出率、退款率确保新页面没有"转化持平、但别的变差"。本数据集没有这些字段，真实业务中必须看
有效性检查两组人数比例（SRM）、每个用户只看到一个页面不通过就先修实验，不看结果
上线规则相对提升 ≥ 2%，p < 0.05，且护栏指标没有变差三条同时满足才上线
停止规则样本量达到预先计算的数量才看结论，中途不因为某天数字好看就停避免"中途偷看"带来的误判

行动清单

优先级行动负责团队具体做什么
P1停止测试，全部用户回到旧页面产品新页面未达到上线标准，继续测试将占用流量
P1修复分流 bug工程 + 数据排查为什么 3,893 名用户被记录了两次、看到了两个页面；之后每次实验上线时自动跑 SRM 检查和"一人一组"检查，不通过就报警
P2复盘新页面，提出下一版假设产品 + 设计 + 数据逐项列出新页面改了什么，结合用户访谈判断哪些改动可能有负面影响。周末和凌晨时段新页面略差（未达显著），可以作为下一版的观察点
P2设计下一轮实验数据见下表：先算好样本量和时长，再开始

下一轮实验设计

设计要素方案
假设针对复盘找出的一个具体改动，比如"缩短首屏文案、突出主按钮，能提高转化率"。一次只验证一个主要改动，结果才说得清
最小有意义的提升相对提升 3%（基线 12.0%，即约 +0.36 个百分点）。比这更小的提升，不值得承担改版成本
样本量与时长每组约 12.9 万人，按每天约 1.3 万新用户计算，需要约 20 天，覆盖完整的周末周期
分流50/50，按用户编号分流，保证同一个用户始终看到同一个页面
决策按上面事先定好的上线规则判断，结论出来前不改规则
一句话向业务方汇报：新页面未带来显著提升，相对提升上限 0.8%，低于 2% 的上线门槛，建议不上线。同时发现分流 bug，需修复后再用约 20 天测试下一版改动。

方法与局限

环节做法
数据清洗SQL：识别分组与页面不一致的记录，整组剔除受污染用户，按用户去重
实验有效性样本比例失衡（SRM）卡方检验，逐日流量检查
主检验双样本比例 z 检验（合并标准误），卡方检验交叉验证；差异的 95% 置信区间（非合并标准误）
功效分析当前样本量下的最小可检测效应；检测 1%–5% 提升所需样本量与天数
稳健性前后半段对比（新奇效应）、累计效果曲线、分群检验与 Bonferroni 校正、不同清洗方式的敏感性分析

局限

  • 只有“是否转化”一个指标，没有客单价、跳出率等护栏指标。真实业务中，即使转化率持平，也要确认新页面没有损害其他指标。
  • 数据集不含用户来源、设备、国家等字段，分群只能按时间维度做。
  • 2% 的上线门槛是假设值，实际应由开发成本和预期收益共同决定。
  • 这是一个公开的教学数据集，适合演示完整的分析流程，不代表某家具体公司的情况。
